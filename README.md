# Professional Calculator

A command-line calculator built with Python, featuring multiple mathematical operations, input validation, and calculation history.

## Features

- Addition, subtraction, and multiplication
- Division with zero-division protection
- Modulo operation
- Exponentiation with input limits
- Input validation using exception handling
- Calculation history
- Continuous operation through an interactive menu
- Accurate decimal arithmetic using Python's `Decimal` module

## Technologies

- Python
- Decimal module
- Git
- GitHub

## Getting Started

### Prerequisites

- Python 3 installed on your computer

### Installation

Clone the repository:

```bash
git clone https://github.com/Mahir-Ceng/professional-calculator.git
```

Navigate to the project directory:

```bash
cd professional-calculator
```

### Run the Application

```bash
python calculator.py
```

## Usage

Choose an operation from the menu:

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Modulo
6. Exponentiation
7. View calculation history
0. Exit

Enter the requested numbers and the calculator will display the result.
